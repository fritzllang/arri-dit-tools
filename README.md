# ARRI DIT Tools

A unified, mobile-friendly interface for two ARRI camera utilities.

## Live application

[Open ARRI DIT Tools](https://fritzllang.github.io/arri-dit-tools/)

## Included tools

1. Formats & Data Rate Calculator
2. Frame Line & Lens Illumination Tool

## Project history

| Version | File | Description |
|---|---|---|
| v1 | `archive/arri-dit-tools-original.html` | Initial prototype |
| v2 | `docs/index.html` | Compact interface and updated layout |

## Technical details

- HTML, CSS and JavaScript
- ARRI tools embedded using iframes
- No external dependencies
- Responsive layout for desktop and mobile
